# Changelog

## 0.1.0-alpha.1

- First crates.io preview release of the Rust Shopify CLI port.
- The published package is `shopirust-cli`; installed command names remain
  `shopify` and `create-app`.
- Native Rust command surfaces are included. Compatibility bridge commands are
  not part of the crates.io preview release.

This is preview software. Verify workflows against a development store before
using it for production deployments.
